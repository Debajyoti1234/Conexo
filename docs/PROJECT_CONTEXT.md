# Conexo

## Vision

Conexo is NOT an event app.

Conexo is a real-world social discovery platform where strangers become friends through small plans hosted by users.

Tagline:

Where Strangers Become Friends.

Mission:

Help people discover genuine human connections through coffee, walks, music, food, travel, gaming, sports, study sessions and other shared experiences.

Core philosophy:

People first.
Plans second.

Never design the app like Meetup or Eventbrite.

Instead think:

Instagram + Airbnb + Discord + Bumble Friends.

The UI should always feel:

- Premium
- Luxury
- Minimal
- Modern
- Calm
- Elegant

Never use generi Flutter demo UI.

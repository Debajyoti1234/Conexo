# WHAT IS CONEXO

Conexo is NOT an event app.

Conexo is NOT Meetup.

Conexo is NOT Eventbrite.

Conexo is NOT Facebook Events.

Conexo is NOT a dating application.

Conexo is NOT a social media platform.

Conexo is a Human Connection Platform.

Mission:

Help people never feel alone.

Everything built inside this application must support that mission.

============================================================

# PRODUCT PHILOSOPHY

Technology does not bring happiness.

People do.

Conexo exists because millions of people eat alone.

Travel alone.

Study alone.

Drink coffee alone.

Move to new cities alone.

Want to make friends but don't know how.

Conexo solves loneliness.

Not networking.

Not dating.

Not events.

Human connection.

============================================================
